## 0.1.0-alpha — 2026-10-20

First public version of the Nexolume site.

- Home page in French and English (`/fr`, `/en`), static export.
- Colour chapters for Writer (blue), Sheets (sage) and Slides (amber).
- A drop zone that tells which Nexolume space opens a `.docx`, `.odt`, `.oswriter`, `.ossheet` or `.osslides` file. The file stays in the browser.
- Limits of the alpha and install steps (Windows x64 ZIP).
- Deployed to GitHub Pages by `.github/workflows/pages.yml`, once Pages is enabled on the repository.
